파급 영향

딸기 병해 관리는 지금까지 육안 관찰에 의존해 왔습니다. 농가의 63%가 조기 발견에 실패하고, 이로 인해 연간 매출의 8~15%를 잃습니다. 이것이 이 사업이 해결하려는 핵심 문제입니다.

시범 농가의 딸기 온실

이 서비스는 이미 시장에 나와 있습니다. 2025년 시범 농가 기준 도입 농가 64곳에서 평균 수확량 17% 증가, 난방비 11% 절감이 확인되었습니다. 검증된 기술 위에 고도화 사업을 올리는 구조입니다.

고도화 기술이 적용될 딸기 온실 재배 현장

사업 기간은 2027년 3월부터 2028년 2월까지 12개월입니다. 총 사업비 6억 원 중 정부 지원금 4.5억 원, 자부담 1.5억 원으로 추진하고, 도입 농가 200곳 확산을 목표로 합니다.

병해 판별, 환경 자동 제어, 출하 시기 예측의 세 가지로 고도화합니다

1

잎 사진 기반 병해 판별 모델

2

온실 환경 자동 제어 연동

생육 상태와 온실 환경 데이터를 연동해 온도와 습도 등 환경 제어를 자동화합니다.

3

출하 시기 예측

생육 데이터 기반으로 최적 출하 시기를 예측해 농가의 출하 계획을 지원합니다.

고도화의 핵심은 세 가지입니다. 첫째 잎 사진 기반 병해 판별 모델, 둘째 온실 환경 자동 제어 연동, 셋째 출하 시기 예측입니다. 세 기능이 문제 정의의 손실을 직접 줄입니다.

데이터 수집, 모델 개발, 현장 실증의 3단계로 12개월을 배치했습니다

1~3개월

데이터 수집

  • 시범 농가 잎 사진·환경 데이터 수집
  • 학습용 데이터셋 구축

4~8개월

모델 개발

  • 병해 판별 모델 개발·고도화
  • 온실 환경 자동 제어 연동 개발
  • 출하 시기 예측 모델 개발

9~12개월

현장 실증

  • 농가 현장 실증 및 성능 검증
  • 도입 농가 확산
12개월을 세 단계로 나눕니다. 1~3개월 데이터 수집, 4~8개월 모델 개발, 9~12개월 현장 실증입니다. 각 단계의 산출물이 다음 단계의 입력이 되도록 배치했습니다.
