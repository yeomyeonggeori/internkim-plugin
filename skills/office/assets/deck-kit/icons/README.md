# Lucide Icons

Lucide 1.49.0, by Lucide Icons and Contributors.

- Source: https://github.com/lucide-icons/lucide
- Download: the npm package `lucide-static@1.49.0`, folder `icons`

Each `.svg` file is copied from the package unchanged. The set holds only the business icons a deck draws with `data-icon`; the file names are the names a slide uses, and `office guide deck` lists them.
